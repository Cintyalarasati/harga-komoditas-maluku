# Checklist Pengujian Manual
## 1. Halaman Website
- [ ] Beranda dapat dibuka.
- [ ] Halaman harga dapat dibuka.
- [ ] Halaman komoditas dapat dibuka.
- [ ] Halaman tentang dapat dibuka.
- [ ] Navigasi antarhalaman berfungsi.

## 2. Fitur Website
- [ ] Pilihan wilayah berfungsi.
- [ ] Data harga tampil sesuai wilayah.
- [ ] Pencarian komoditas berfungsi.
- [ ] Tombol reset pencarian berfungsi.
- [ ] Modal foto profil dapat dibuka dan ditutup.

## 3. Dashboard Admin
- [ ] Login admin berhasil dengan akun yang benar.
- [ ] Login ditolak dengan kata sandi yang salah.
- [ ] Dashboard admin dapat dibuka.
- [ ] Logout berfungsi.

## 4. Tampilan dan Responsivitas
- [ ] Tampilan desktop sesuai.
- [ ] Tampilan tablet sesuai.
- [ ] Tampilan HP sesuai.
- [ ] Gambar dan favicon tampil.
- [ ] Tidak ada kesalahan JavaScript di Console browser.

## 5. Keamanan dan Konfigurasi
- [ ] File konfigurasi rahasia tidak masuk Git.
- [ ] Database dapat terhubung.
- [ ] Halaman admin tidak dapat diakses tanpa autentikasi.
